# 网站配置

网站配置页面位于「平台管理 → 网站配置」，仅超级管理员可读写。页面包含系统标识、登录体验、SEO、联系与合规四组，另有状态概览和发布预览。重置恢复上次读取或发布的配置，不会清空数据库。

## 数据库与发布

前端项目：`D:/code_practice/liteS`。后端项目：`D:/code_practice/liteShop_admin_miniSer`。

1. 在 MySQL 中执行后端 `sql/vertical-split/13_website_config.sql`。这是增量脚本，可以重复执行，不覆盖已有网站配置；不要重新执行会删除旧表的初始化脚本。
2. 部署或重启 `liteShop-config-service` 和 `liteShop-user-service`（同时构建更新后的 common、api 模块）。用户服务现在通过内部 Feign 接口读取配置服务，需保证服务发现和内部调用密钥配置正常。
3. 构建并部署前端，超级管理员重新登录后进入「网站配置」。

`liteshop_config.sys_config` 继续保存商户小程序配置。新增 `liteshop_config.sys_website_config` 保存管理端全局配置，因为管理端登录时尚未选定商户。

新表只有一条记录，`id=1`；`config_value` 为经过后端类型和长度校验的 JSON，`revision` 用于并发更新校验，`updated_by` 和 `updated_at` 记录最后发布者与时间。不需要按四个分组建四张表。数据库和 JSON 内的版本号由发布事务一起更新。

## 读取与缓存

- 浏览器启动读取一次公开配置，保存在共享 Pinia / Vue 状态中；切换页面或配置分组不重复请求。
- 当前标签页发布成功后立即应用配置；同一浏览器的其他同源标签页收到通知后重新获取公开配置。
- 页面重新获得焦点时，如果超过 60 秒没有读取则刷新；登录提交前重新检查配置。其他设备在刷新页面或重新聚焦后获取变更。
- 配置服务优先读取共享 Redis，缓存有效期 60 秒，未命中才查数据库；发布事务提交后同步缓存。Redis 写入通过版本比较避免旧读取覆盖新配置。
- Redis 不可用时，公开读取回源数据库；发布缓存同步失败时，已有缓存最多保留 60 秒。数据库读取失败不会把内置默认值发布为真实配置。

接口：

| 接口                         | 用途                                                           |
| ---------------------------- | -------------------------------------------------------------- |
| `GET /config/website/public` | 匿名读取公开字段白名单，不返回锁定阈值、时长、审计数据         |
| `GET /config/website/admin`  | 超级管理员读取最新数据库配置                                   |
| `PUT /config/website/admin`  | 超级管理员校验并发布整份配置；版本冲突返回 409                 |
| `GET /inner/config/website`  | 用户服务读取登录策略；网关禁止外部访问，服务端验证内部调用凭据 |
| `GET /user/admin/captcha`    | 获取两分钟有效的图片验证码                                     |

## 生效范围

- 系统名称：登录页、顶栏、侧栏、浏览器标题；简介：登录页品牌说明及 SEO 描述的备用值。
- 水印：用户名、用户名加时间、系统名称、自定义文本。只在登录后的后台展示；个人设置面板可临时隐藏，刷新后恢复站点配置。
- 默认语言：应用于未手动选择语言的用户；不会覆盖已选择的个人语言。管理员填写的文案按原文显示，不做自动翻译。
- 图片验证码：密码及短信 / 邮箱验证码登录都需提交 `captchaId`、`captchaCode`，由服务端消费校验，成功或失败均不能复用。没有提供仅在前端校验的滑块模式。
- 失败锁定：按规范化后的登录账号统计，15 分钟窗口内达到配置的失败次数后锁定指定分钟；登录成功清除失败次数。留空时禁用可配置的失败锁定，保留原有请求频率限制。已有锁定在到期前不会随失败请求延长。
- 维护模式：展示公告，阻止普通管理员获取商户选择凭证和完成商户登录；超级管理员验证身份后仍能登录以关闭维护。已登录的业务会话不会被强制退出。
- 防绕过：启用任意登录安全控制或维护模式后，管理账号通过旧用户登录、用户验证码或微信登录入口不能获取管理会话，必须走管理端安全验证。普通顾客账号不受影响。
- 联系方式、地址、版权和备案文案：登录页页脚显示；空字段自动隐藏。备案链接固定指向备案查询站点，所有文案作为纯文本渲染。
- SEO：更新浏览器标题与 `description`、`keywords`、`application-name` 元信息。当前管理端为客户端渲染应用，不保证搜索收录；后续建设公开官网时可以复用公开接口，在服务端渲染这些元信息。

## 验证

后端单元测试覆盖缓存命中、提交后同步、版本冲突、公开字段过滤、条件校验、验证码复用、账号锁定、配置服务故障、维护与旧入口防绕过，并回归现有租户登录。

前端检查包括 TypeScript、生产打包、产物全局变量检查及现有 16 项集成测试。`scripts/verify-website-ui.mjs` 使用本地模拟网关验证保存、重置、跨标签同步、标题、水印、验证码、页脚和窄屏布局；该模拟数据不写入真实数据库。先运行 `scripts/mock-gateway.mjs`（18080），再运行将 API 代理指向该端口的 Vite（15173）。浏览器脚本使用 Playwright 和无界面 Edge，可用 `PLAYWRIGHT_MODULE` 指定本机 Playwright 的入口文件。
