# 业务修复与部署说明（2026-09-03）

本次修改位于 liteS 和 liteShop_admin_miniSer 源码。保留旧版业务页面布局，复用主项目的 Art 组件，组件示例位于 D:/Microsoft Edge Download/art-design-pro-main/art-design-pro-main。

## 对应需求

| 功能 | 修改后的行为 |
| --- | --- |
| 指定用户发券 | 可直接粘贴完整用户 ID，也可按姓名/手机号搜索；ID 不经过 Number 转换。只允许当前租户用户，两个时间可以分别留空。缺省有效期为 3 天且不超过券截止时间，校验失败不扣库存。 |
| 餐桌收银 | 空闲桌可预留、停用；预留桌可取消预留；停用桌可恢复空闲。正在使用或存在会话的桌位不能手动改状态。状态修改和开桌使用同一桌位行锁。 |
| 角色权限 | 菜单按数据库授权展示，去掉前端按固定门店角色额外裁剪。业务接口按对应菜单权限校验；停用角色不产生权限。勾选目录可联动下级，保存失败会明确返回错误；禁止跨租户分配、普通授权员改管理员角色、通过分配角色扩大自己的权限。 |
| 门店授权 | 默认展示已授权人员、用户 ID、已授权门店和真实默认门店；支持按用户/门店/授权状态查询及调整。新增授权可搜索人员。租户管理员显示全部门店。 |
| 图标库 | 菜单管理顶部可直接打开图标库，共 3,558 个图标（Remix 3,229 个、Icons8 彩色 329 个），支持中文名称、中英文关键词搜索、分类、分页和复制名称。点击星标可加入或移出“我的常用”，初始推荐 54 个，收藏按账号保存在本浏览器。菜单、菜品分类、会员等级的图标字段支持直接选择。两套图标均随前端打包，不依赖外网加载、不需要导入数据库。允许图片的字段仍支持图片地址。 |
| 会员等级 | 平台维护多套模板；租户可引用模板或创建自己的多套方案，每次启用一套。模板以复制方式引用，之后独立维护。方案切换按会员原有经验计算等级，保留经验、余额和积分。 |
| 新租户默认项 | 自动创建默认角色和启用的等级方案；配置服务初始化 23 个常用配置键（应用名、主题、图片、公告、联系信息、二维码等）。已填写的配置不覆盖；配置服务暂不可用时，后续读取会补齐默认项。外部通道地址/密钥保留空值，由实际运营配置。 |
| 组件与操作栏 | 业务页面的表格/表单已接入 ArtTable/ArtForm。会员等级、角色、商户管理、门店授权的操作栏统一复用菜品管理的 ArtButtonTable，采用 32px 浅色底图标按钮，支持禁用、键盘焦点和名称提示。 |

多角色用户的权限取各个启用角色的并集。菜单权限决定可以操作哪些业务模块，门店授权决定这些模块可访问哪些门店；两者必须同时满足。角色分配保存后更新门店范围会话；切换账号/租户会重新加载身份和菜单。其他已登录客户端的侧栏需刷新页面才能重新展示，接口权限以最新数据库授权为准。

## 数据库迁移（由用户执行）

文件：D:/code_practice/liteShop_admin_miniSer/sql/vertical-split/12_member_level_schemes.sql。

1. 确认前序 11_add_database_driven_menus.sql 已执行；未执行的先执行 11。
2. 备份 liteshop_user，暂停旧 user-service 的写入，再执行 12_member_level_schemes.sql（MySQL 8.0）。
3. 12 将原全局等级保留为平台默认模板，为现有租户复制独立的启用方案，并添加平台会员等级模板菜单。不会重新授予已有菜单中被撤销的权限，也不修改已有会员经验、等级、余额、积分。

5. 部署本次构建的 config、user、restaurant、coupon、lottery 服务与前端 dist；建议先启用 config，再启用 user。这些模块需要使用同一次构建的 common/api 依赖。刷新浏览器或重新登录。

DDL 在 MySQL 中会隐式提交；迁移数据另有事务。脚本支持在保留已完成结构的情况下重跑。执行迁移以前，不要让新版 user-service 连接旧结构。按用户约定，本轮未执行迁移 SQL、未重启真实业务服务。

## 迁移后的验收流程

1. 用当前租户内存在的会员 ID 发券，分别测试时间留空和指定时间；核对用户券增加、库存减少。另租户 ID、过期时间和无效 ID 应失败，库存不变。
2. 空闲桌设为预留，再取消预留；停用后不能开桌，恢复后可以开桌；正在使用的桌不能手动预留/停用。
3. 给测试店员只分配餐桌收银等指定菜单与一家门店，退出并登录该店员，核对侧栏与门店范围；未分配的业务接口应拒绝。若用户有多个角色，请一并检查所有角色。
4. 在门店授权列表查看已授权用户，调整门店和默认门店，再以该用户重新登录核对。
5. 平台模板复制给租户 A 后修改 A 的方案，租户 B 与平台模板均不应变化；切换方案后，会员等级随经验重新计算，余额/积分/经验保持原值。
6. 新建租户后查看默认角色、当前启用等级方案和基础配置；修改一项配置，再刷新确认初始化未覆盖已填写值。
