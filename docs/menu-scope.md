# 菜单显示范围

超级管理员的身份和当前租户范围是两个维度。退出租户后隐藏订单、门店等租户页面是正常行为；平台等级体系应该有独立入口。

新环境执行新版 `docs/sql/16_menu_scope.sql`；已执行旧版16脚本的环境执行 `docs/sql/17_menu_scope_numeric.sql`（MySQL 8，目标库 `liteshop_user`），再重启用户服务并刷新前端。16号脚本初始化范围和缺失的平台等级入口；17号脚本只转换已有范围字段，不改菜单和授权。已有菜单禁用状态、隐藏状态或已撤销的授权均保留。维护窗口暂停写入后执行；DDL 隐式提交，转换异常值会提前报错，修正后可重跑。

在“菜单管理 → 编辑菜单 → 显示范围”设置：

数据库字段使用 `TINYINT UNSIGNED`，后端 `MenuScopeEnum` 通过 `@EnumValue` 映射存储值，接口统一传递数字，前端显示中文标签。兼容升级期间的旧字符串输入，非法值直接拒绝；按钮/API的NULL表示随所属页面。

| 范围          | 退出租户         | 进入租户         |
| ------------- | ---------------- | ---------------- |
| 1：仅平台     | 超级管理员可见   | 隐藏             |
| 2：仅租户     | 隐藏             | 有相应权限时可见 |
| 0：平台和租户 | 有相应权限时可见 | 有相应权限时可见 |

目录根据其可见子菜单显示，按钮继承页面。隐藏或禁用规则和角色授权仍生效。`platform:` 权限码及平台组件始终要求超级管理员身份，即使将范围设置为“两者”。

平台等级体系：组件 `platform/level-template/index`，权限码 `platform:level-template`，推荐范围“仅平台”；用于配置模板、设置全局默认、分配模板给租户。

租户会员等级：组件 `system/level/index`，权限码 `system:level`，推荐范围“仅租户”；用于选择获分配模板、复制并维护租户等级。

“两者”适用于本身支持两种上下文的页面，例如会员等级页面会根据租户上下文展示平台模板或租户方案。修改菜单范围不会为订单等页面增加跨租户能力，也不会放开后端鉴权。

若平台入口仍不显示，查看脚本最后的查询：菜单状态应启用、未隐藏、`super_admin_granted=1`，且父目录启用。已有菜单撤销过授权时，需要在角色权限配置中重新授予；不要通过前端虚构菜单绕过数据库授权。
